# 📝 演習課題: 自己紹介ファイルを追加しよう

このフォルダに **自分の名前のファイル** を追加して、Pull Request でマージしてもらうのが課題です。

## ルール

1. ファイル名は `自分の名前.md`(ローマ字)。例: `taro.md`
2. `_sample.md` をコピーして書き換えると簡単
3. **他の人のファイルは編集しない**(自分のファイルだけ!)
4. ブランチ名は `feature/add-自分の名前`。例: `feature/add-taro`
5. PR の送り先(base)は `develop`

手順がわからなくなったら [docs/hands-on.md](../docs/hands-on.md) を見てください。
