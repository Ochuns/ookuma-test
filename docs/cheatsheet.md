# 📖 Git コマンド チートシート

## 状態を見る

| コマンド | 意味 |
| --- | --- |
| `git status` | 今いるブランチと、変更されたファイルを表示 |
| `git branch` | ローカルのブランチ一覧(`*` が今いる場所) |
| `git branch -a` | GitHub 側のブランチも含めた一覧 |
| `git log --oneline` | コミット履歴を1行ずつ表示 |
| `git log --oneline --graph --all` | ブランチの枝分かれを図で表示 |
| `git diff` | まだ add していない変更の中身を表示 |

## ブランチを操作する

| コマンド | 意味 |
| --- | --- |
| `git switch ブランチ名` | ブランチを移動する |
| `git switch -c 新ブランチ名` | ブランチを新しく作って移動する |
| `git branch -d ブランチ名` | ブランチを削除する(マージ済みのみ) |

## 変更を記録する

| コマンド | 意味 |
| --- | --- |
| `git add ファイル名` | コミットする対象を選ぶ(ステージング) |
| `git add .` | 変更した全ファイルを対象にする |
| `git commit -m "メッセージ"` | セーブポイントを作る |

## GitHub とやりとりする

| コマンド | 意味 |
| --- | --- |
| `git clone URL` | リポジトリを PC にコピーする(最初の1回だけ) |
| `git pull origin ブランチ名` | GitHub の最新状態を取り込む |
| `git push origin ブランチ名` | 自分のコミットを GitHub に送る |

## 困ったときは

| コマンド | 意味 |
| --- | --- |
| `git restore ファイル名` | ファイルの変更を取り消す(add 前) |
| `git restore --staged ファイル名` | add を取り消す(変更自体は残る) |
| `git switch -` | 直前にいたブランチに戻る |

> ⚠️ `git reset --hard` や `git push -f` は変更が消える危険なコマンドです。
> 使う前に必ず周りの人に相談しましょう。

## 用語ミニ辞典

| 用語 | 意味 |
| --- | --- |
| リポジトリ | プロジェクトの保管庫(履歴ごと入っている) |
| ブランチ | 作業を分けるための「枝」。分身の作業スペース |
| コミット | 変更のセーブポイント |
| origin | クローン元(GitHub 上のリポジトリ)のあだ名 |
| マージ | ブランチの変更を別のブランチに合流させること |
| コンフリクト | 同じ場所を別々に変更してマージできない状態 |
| Pull Request (PR) | 「この変更を取り込んで」という提案。レビューの場 |
